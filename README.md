## 🎞 반복되는 질문으로 인터뷰하는 자기개발앱

**innerView**는  inner + interview로 내면을 인터뷰하는 의미입니다. 

1년, 1달, 일주일 간격으로 같은 질문에 답변하여 자신의 변화 과정을 *기록해 보세요.* 혹은 매일 다른 질문으로 하루를 기록해 볼 수도 있습니다.
